1. Rappels

1.1 Dénotation, Sens et Représentations (pragmatiques)

Selon Gottlob Frege, la signification d'une expression s'articule autour de trois dimensions :

« La dénotation d'un nom propre est l'objet même que nous désignons par ce nom ; la représentation que nous y joignons est entièrement subjective ; entre les deux gît le sens, qui n'est pas subjectif comme l'est la représentation, mais qui n'est pas non plus l'objet lui-même. »
— Frege G., Écrits logiques et philosophiques (ELG)
  • Dénotation : Objet du monde désigné (par exemple par un nom propre).
  • Sens : Objectif, commun à tous les locuteurs. Il relève de la sémantique.
  • Représentation : Subjective, elle relève de la pragmatique.

1.2 Valeurs de vérité et conditions de vérité

  • Valeurs de vérité : Elles correspondent au Vrai (1) et au Faux (0). Si les groupes nominaux dénotent des individus, les phrases dénotent le Vrai ou le Faux.
  • Le sens est ce qui va nous permettre de retrouver la dénotation.
  • Le sens d'une phrase est l'ensemble de ses conditions de vérité.
  • Conditions de vérité :
    • La façon dont le monde doit être pour que cette phrase soit vraie ;
    • Les caractéristiques communes à tous les scénarios où la phrase est vraie.

1.3 Modélisation à l'aide de la logique des prédicats

Les éléments du Langage Objet (LO) :

  • Constantes : Des symboles dont la dénotation ne varie pas. Elles équivalent aux noms propres de LO.
  • Prédicats : Servent à dire quelque chose sur quelque chose ou quelqu'un.
  • Argument : Ce à quoi s'applique le prédicat.
  • Arité : Le nombre d'arguments que le prédicat admet. Elle est toujours fixe, jamais variable.
  • Variables : Symboles dont la dénotation peut varier en fonction du contexte, tout comme le font les pronoms dans le langage naturel.
    Notation (Roussarie [2017], p.64) :
    Dans LO, les variables seront notées par des lettres, de préférence minuscules, en italiques, prises à la fin de l'alphabet : principalement x, y, z, mais aussi parfois u, v, w. Elles pourront être éventuellement complétées d'indices numériques : x1, x2, x3, y1..., ou de primes : x', x''....
  • Connecteurs logiques : Symboles permettant de former des formules à partir d'autres formules (ex. ¬, ∧, ∨, →, ↔).

Syntaxe de LO

  1. Si a est une variable ou une constante (d'individu), a est un terme ;
  2. Si a et b sont des termes, a = b est une formule (atomique) ;
  3. Si a1, ..., an sont des termes et p un prédicat d'arité n (où n est un entier naturel), p(a1, ..., an) est une formule ;
  4. Si φ et ψ sont des formules, ¬φ, [φ ∧ ψ], [φ ∨ ψ], [φ → ψ] et [φ ↔ ψ] le sont aussi.

2.2 Principe de Compositionnalité

« Le sens d'une expression linguistique est construit à partir de celui de ses composantes et de la façon dont elles sont agencées. »
Questions

  2. Comment est construite la signification de la phrase « Ali vient » ?

La Conjecture de Frege

Activité
  1. On donne le corpus suivant :
    • (i) Ali vient.
    • (ii) Kouassi vient.
    • (iii) Fatou vient.
  2. Formalisez la dénotation des noms propres du corpus.
  3. On donne le contexte suivant :
    Contexte : Il y a une fête de prévue. Vous avez appelé tous les invités pour qu'ils confirment ou non leur participation. Parmi ceux qui ont confirmé se trouvent Kouassi et Fatou, mais Ali a dit qu'il n'était finalement pas disponible.
    1. Formalisez la signification des phrases (i) à (iii) ci-dessus.
    2. Donnez la dénotation de chaque formule d'après le modèle M compatible avec ce contexte (Astuce : cela revient à trouver la valeur de [[...]]M pour chaque formule proposée).
    3. Quel est donc le rôle du prédicat dans la signification des phrases (i) à (iii) ?

Correction de l'activité

  • Analyse des noms propres :
    • Ali → a
    • Kouassi → k
    • Fatou → f
  • Signification et Dénotation dans le Modèle M :
    • (i) Ali vient. Formule : venir(a). Évaluation : [ [ venir(a) ] ]M = 0 (Faux)
    • (ii) Kouassi vient. Formule : venir(k). Évaluation : [ [ venir(k) ] ]M = 1 (Vrai)
    • (iii) Fatou vient. Formule : venir(f). Évaluation : [ [ venir(f) ] ]M = 1 (Vrai)
  • Rôle du prédicat : Le prédicat retourne une valeur de vérité à partir d'un individu. Ainsi, venir dénote une fonction !
« On peut envisager de décomposer les propositions affirmatives comme les équations, les inéquations, et les expressions analytiques, en deux parties dont l'une est fermée sur soi et dont l'autre réclame un complément, est insaturée. On analysera par exemple la proposition "César conquit les Gaules" en "César" et "conquit les Gaules". La seconde partie est insaturée, elle traîne une place vide avec elle, et ce n'est qu'après avoir rempli cette place par un nom propre ou une expression qui représente un nom propre qu'on voit naître un sens fermé sur lui-même. J'appelle ici encore fonction la dénotation de la partie insaturée. Dans ce cas, l'argument est César. »
— Frege G., Fonction et Concept (1891), Ecrits Logiques et Philosophiques, p. 91.
La Conjecture de Frege
La composition sémantique est une application de fonction.

2.3 Implémenter la conjecture de Frege

2.3.1 Remarques informelles sur les fonctions

  • Selon Frege : Une fonction n'est pas un nombre ; c'est une expression incomplète (insaturée) qui demande un objet pour être complète et générer quelque chose.
  • Selon Church (1941:1) : Une fonction est une règle qui permet, à partir d'un objet donné - appelé argument - d'obtenir un autre objet - appelé image.
  • Les fonctions s'appliquent à des objets d'un type sémantique particulier.

2.3.2 Des types dans les langues naturelles

Deux types basiques forment notre ontologie sémantique :

  • e : Le type des objets / individus.
  • t : Le type des phrases (valeurs de vérité).

Types fonctionnels :

  • Concepts (dénotation des prédicats intransitifs) : e → t (ou noté ⟨e, t⟩)
  • Généralisation : a → b (fonctions prenant des objets de type a et retournant des objets de type b).
  • Notation : ⟨a, b⟩ désigne le type des fonctions qui prennent un argument de type a et renvoient un résultat de type b.
  • Types récursifs : Cas des verbes transitifs et de la Schönfinkelisation.
Exercice

Combien de prédicats avons-nous dans la phrase ci-dessous ?

Jean tapa Karim.

Réponse : Au moins deux : "... tapa Karim" et "tapa ...". Dans cette phrase, on a une fonction qui prend un argument et renvoie une autre fonction, laquelle prend à son tour un argument pour finalement renvoyer une valeur de vérité.

Généralisation : Toute fonction à n arguments peut être décomposée en n fonctions successives à 1 argument. C'est le principe de la currification (ou schönfinkelisation).

Définition : Les Types (T)
Soit la classe des types d'expressions. T est la plus petite classe telle que :
  1. e, t ∈ T ;
  2. Si a, b ∈ T, alors ⟨a, b⟩ ∈ T.

2.3.3 Formalisation directe ou formalisation indirecte des significations

Montague (1973) propose deux options de formalisation des significations :

  • Formalisation directe : Associer directement les expressions linguistiques à des objets du modèle mathématique.
    F(venir) = λx [1 ssi x vient]
  • Formalisation indirecte (ou traduction) : Associer les expressions linguistiques à des expressions d'un langage logique intermédiaire (le Langage Objet), qui sont elles-mêmes associées à des objets du modèle.
    venir → λx [venir(x)]
    Où [ [ λx [venir(x)] ] ]M = f, la fonction qui, à tout x dans son domaine, assigne la valeur de vérité 1 ssi x vient (et 0 le cas échéant).

Dans ce cours, nous adoptons l'approche indirecte de la formalisation (pour l'approche directe, voir Montague (1970), Heim & Kratzer (1998), Akpoué (Ms)).

2.4 Une idéographie pour représenter le sens linguistique

L'approche indirecte consiste à traduire les expressions linguistiques dans un langage artificiel. Nous utiliserons les symboles logiques comme des idéogrammes (représentant les concepts sémantiques). Les idéogrammes appartiennent à des types sémantiques. Pour chaque type a, on définit un ensemble de variables Vara et un ensemble de constantes Cona. La variable vn,a désigne la n-ième variable de type a.

Définition : Idéogramme (ME de Montague, 1973)
Soit Ia l'ensemble des idéogrammes de type a.
  1. Toutes les variables et les constantes de type a sont des idéogrammes de type a ;
  2. Si α est un idéogramme de type a, et v une variable de type b, alors λv[α] est un idéogramme de type ⟨b, a⟩ ;
  3. Si α est un idéogramme de type ⟨a, b⟩ et β un idéogramme de type a, alors α(β) est un idéogramme de type b ;
  4. Si α et β sont des idéogrammes de type a, alors α = β est un idéogramme de type t ;
  5. Si φ et ψ sont des idéogrammes de type t, alors ¬φ, [φ ∧ ψ], [φ ∨ ψ], [φ → ψ], et [φ ↔ ψ] sont des idéogrammes de type t ;
  6. Si v est une variable, et φ un idéogramme de type t, alors ∀vφ et &exists;vφ sont des idéogrammes de type t ;
  7. Rien d'autre n'est un idéogramme.

Interprétation des idéogrammes

Interpréter un idéogramme consiste à déterminer sa dénotation (ou sa valeur) en fonction de deux paramètres : un modèle et une fonction d'assignation de valeurs aux variables.

Définition : Modèle
Un modèle M est une représentation mathématique d'un état du monde : M = ⟨D, F⟩, où D est le domaine des individus et F est la fonction d'interprétation qui assigne à chaque constante sa dénotation dans le super-domaine sémantique A.

Exemple : F(λx[venir(x)]) = f, la fonction qui à tout individu x ∈ D associe 1 ssi x vient, et 0 sinon.

Assignation : La fonction d'assignation g attribue des valeurs aux variables. Par exemple :

  • g(x1,e) = P (un individu particulier).
  • g(P2,⟨e,t⟩) = f', la fonction qui retourne 1 ssi l'individu donné est un enseignant de sémantique formelle.

Modification d'une assignation : On note g[u/v] la fonction d'assignation g modifiée de sorte qu'elle assigne l'entité u à la variable v, tout en conservant les mêmes assignations pour toutes les autres variables.

Définition ensembliste des fonctions

Fonction
Soit A, B et f des ensembles. f est une fonction de A vers B ssi f est un ensemble de couples (a, b) tels que a ∈ A et b ∈ B, et pour tout a ∈ A, il n'existe pas deux éléments distincts b, c ∈ B tels que (a, b) ∈ f et (a, c) ∈ f.
  • Domaine : Ensemble de départ (noté dom(f)).
  • Argument : Élément du domaine.
  • Image : Élément de l'ensemble d'arrivée associé à l'argument. Si ⟨x, y⟩ ∈ f, alors x est l'argument et y est l'image (noté f(x) = y).

Règles d'interprétation des idéogrammes

La valeur sémantique d'un idéogramme α sous un modèle M et une assignation g est notée [[ α ]]M,g :

  1. Si α est une constante, [[ α ]]M,g = F(α) ;
  2. Si α est une variable, [[ α ]]M,g = g(α) ;
  3. Si v est une variable de type a et α un idéogramme de type b :
    [[ λv[α] ]]M,g est la fonction h : Da → Db telle que pour tout x ∈ Da, h(x) = [[ α ]]M, g[x/v] ;
  4. Si α est de type ⟨a, b⟩ et β de type a :
    [[ α(β) ]]M,g = [[ α ]]M,g([[ β ]]M,g) ;
  5. Si α et β sont de type a :
    [[ α = β ]]M,g = 1 ssi [[ α ]]M,g = [[ β ]]M,g ;
  6. Si φ est de type t :
    [[ ¬φ ]]M,g = 1 ssi [[ φ ]]M,g = 0 ;
  7. Si φ et ψ sont de type t :
    [[ φ ∧ ψ ]]M,g = 1 ssi [[ φ ]]M,g = 1 et [[ ψ ]]M,g = 1 ;
  8. Si φ et ψ sont de type t :
    [[ φ ∨ ψ ]]M,g = 1 ssi [[ φ ]]M,g = 1 ou [[ ψ ]]M,g = 1 ;
  9. Si φ et ψ sont de type t :
    [[ φ → ψ ]]M,g = 1 ssi [[ φ ]]M,g = 0 ou [[ ψ ]]M,g = 1 ;
  10. Si φ et ψ sont de type t :
    [[ φ ↔ ψ ]]M,g = 1 ssi [[ φ ]]M,g = [[ ψ ]]M,g ;
  11. Si v est une variable et φ de type t :
    [[ &exists;vφ ]]M,g = 1 ssi au moins un individu u ∈ D est tel que [[ φ ]]M, g[u/v] = 1 ;
  12. Si v est une variable et φ de type t :
    [[ ∀vφ ]]M,g = 1 ssi pour tous les individus u ∈ D, [[ φ ]]M, g[u/v] = 1.

Conversion lambda (λ-réduction) : Pour toute variable v de type a, tout terme β de type a et tout idéogramme α, le schéma de réduction suivant s'applique : λv[α](β) ↔ α (où toutes les occurrences libres de v dans α sont remplacées par β).

3. Application à des fragments de langue

3.1 Interprétation nœud par nœud

Activité sémantique
  1. Soit le mini-corpus suivant :
    • (i) Fatou appelle Koffi.
    • (ii) Koffi arrive.
  2. Proposez une traduction logique de tous les mots composants ce corpus.
  3. Proposez une représentation arborescente (en supposant une structure binaire standard de syntagme verbal VP) pour ces phrases.
  4. À partir de la traduction lexicale et de la structure syntaxique, montrez pas à pas comment le sens global est construit.

Correction de l'activité

a. Lexique et traductions :

  • Fatou → f
  • Koffi → k
  • arrive → λx [arriver(x)]
  • appelle → λx [λy [appeler(y)(x)]]

b. Structures syntaxiques et arbres de dérivation :

Arbre pour la phrase intransitive : "Koffi arrive"
            VP [arriver(k)] (type t)
           /  \
       DP [k]  V [λx[arriver(x)]] (type <e,t>)
        |       |
      Koffi   arrive

Calcul sémantique : L'application de fonction donne λx[arriver(x)](k) qui se réduit par λ-conversion à arriver(k).

Arbre pour la phrase transitive : "Fatou appelle Koffi"
                  VP [appeler(f)(k)] (type t)
                 /  \
            DP [f]   V' [λy[appeler(y)(k)]] (type <e,t>)
             |      /  \
           Fatou   V    DP [k]
                   |     |
                appelle Koffi

Calcul sémantique pas à pas :

  1. Au nœud intermédiaire V' : λx[λy[appeler(y)(x)]](k) se réduit à λy[appeler(y)(k)] par substitution de x par k.
  2. Au nœud maximal VP : λy[appeler(y)(k)](f) se réduit à appeler(f)(k) par substitution de y par f.
